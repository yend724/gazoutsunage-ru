# プロダクト要求定義書 - ガゾウツナゲール

## 1. プロダクトビジョンと目的

### ビジョン
「ガゾウツナゲール」は、画像結合作業を劇的に簡単にするWebアプリケーションです。
従来の画像編集ソフトでは数十分かかっていた作業を、わずか3ステップ・1分以内で完了できます。

**他サービスとの差別化ポイント：**
- **完全プライベート処理**：画像データが一切外部に送信されない
- **超高速処理**：ローカル処理により即座に結果を確認
- **ゼロインストール**：ブラウザだけで完結、どこからでもアクセス可能
- **直感的操作**：説明書を読まずに操作できるシンプルなUI

### 目的
- 複数の画像を1つに結合する作業時間を90%短縮する
- プライバシーを重視したローカル完結型の画像処理を提供
- 技術スキルを問わず、誰でも美しい画像結合を実現
- SNS投稿、EC運営、業務効率化の支援

## 2. ターゲットユーザーと課題・ニーズ

### 主要ターゲットユーザー

#### プライマリターゲット
**ビジネス利用者**（利用頻度：月数回〜週1回）
- 会社員の経費精算（領収書の結合）
- 個人事業主の確定申告書類整理
- 契約書・請求書などの書類管理
- 資料作成での画像まとめ

#### セカンダリターゲット  
**SNS・コンテンツ投稿者**（利用頻度：月数回）
- Instagram、Twitter等への投稿用画像作成
- 複数の写真を1つのストーリーにまとめる
- 趣味の写真整理・アルバム作成

### 解決する課題
- **書類管理の煩雑さ**: 複数の領収書や書類を1つのファイルにまとめる作業が面倒
- **プライバシーの懸念**: 個人情報や機密書類を外部サーバーにアップロードしたくない
- **ソフトウェアの複雑さ**: PhotoshopやWordなどの重いソフトを起動するのが手間
- **時間効率の悪さ**: 簡単な作業なのに10分以上かかってしまう

## 3. 主要な機能一覧

### コア機能
1. **画像アップロード**
   - ドラッグ&ドロップによる複数画像の一括アップロード
   - ファイル選択ダイアログからの選択
   - 対応形式: JPEG, PNG, WebP, GIF

2. **画像配置**
   - 横並び配置
   - 縦並び配置
   - グリッド配置（2×2、3×3など）
   - カスタム配置

3. **画像調整**
   - 画像の並び替え（ドラッグ&ドロップ）
   - 個別画像の削除
   - 全体のマージン調整
   - パディング調整

4. **プレビュー機能**
   - リアルタイムプレビュー
   - ズームイン・ズームアウト
   - フィット表示

5. **画像出力**
   - 形式選択（JPEG, PNG, WebP）
   - 品質設定（JPEGの場合）
   - ダウンロード機能

### 追加機能（フェーズ2）
- 画像の回転・反転
- 背景色の設定
- 画像へのテキスト追加
- フィルター適用
- テンプレート機能

## 4. 成功の定義

### ユーザー関連KPI（測定期間：リリース後3か月）
- **月間アクティブユーザー数（MAU）**: 1,000人以上
- **リピート率**: 30%以上（1週間以内の再訪問）
- **タスク完了率**: 90%以上（画像アップロード～ダウンロード完了）
- **平均セッション時間**: 2-5分（効率的な作業時間）
- **ユーザー満足度**: 4.0/5.0以上（アプリ内フィードバック）

### 技術的指標
- **ページ読み込み時間**: 3秒以内（3G回線）
- **画像処理時間**: 10MB画像で5秒以内
- **ブラウザサポート率**: 95%以上
- **エラー率**: 1%未満（処理失敗率）
- **メモリ使用効率**: 500MB以下での安定動作

### 定性的指標（ユーザビリティ）
- 初回利用者が説明書なしで基本操作を理解できる
- 画像結合が3ステップ以内で完了する
- ユーザーがプライバシーの安全性を感じる

「個人情報が含まれる書類をスキャンして結合したい。

## 7. 受け入れ条件

### 機能要件の受け入れ条件
- [ ] 5枚以上の画像を同時にアップロードできる
- [ ] 3種類以上の配置パターンが選択できる
- [ ] プレビューが1秒以内に更新される
- [ ] 3種類の出力形式から選択できる
- [ ] 結合した画像をダウンロードできる

### 非機能要件の受け入れ条件
- [ ] モバイルデバイスでも操作可能
- [ ] 画像データがサーバーに送信されない
- [ ] 10MBの画像を5秒以内に処理できる
- [ ] Chrome, Safari, Firefox, Edgeで動作する

## 8. 機能要件（シンプル版）

### FR-001: 画像アップロード機能
- **ファイル選択**: クリックまたはドラッグ&ドロップ
- **対応形式**: JPEG, PNG のみ
- **ファイルサイズ制限**: 1枚あたり最大5MB、合計最大20MB
- **同時アップロード**: 最大10枚
- **エラー表示**: 「ファイルサイズが大きすぎます」などのシンプルなメッセージ

### FR-002: 画像配置機能
- **横並び配置**: 左から右に画像を並べる（デフォルト）
- **縦並び配置**: 上から下に画像を並べる
- **並び替え**: 画像をクリックで選択、矢印ボタンで移動

### FR-003: 画像調整機能
- **余白調整**: 10px単位でスライダー調整（0-50px）
- **画像削除**: 個別の✕ボタンで削除
- **全削除**: 「すべてクリア」ボタン

### FR-004: プレビュー機能
- **リアルタイムプレビュー**: 変更時に即座に反映
- **表示**: 画面内に収まるサイズで表示

### FR-005: 画像出力機能
- **形式**: PNG固定（透明背景保持のため）
- **背景**: 透明背景（白背景ではなく透明を維持）
- **ファイル名**: 「merged_YYYYMMDD_HHMMSS.png」の自動生成
- **ダウンロード**: 「ダウンロード」ボタンでローカル保存

## 9. 非機能要件

### NFR-001: パフォーマンス要件
- 初回ロード: 3秒以内（3G回線）
- 画像処理: 1MB/秒以上の処理速度
- メモリ使用量: 最大500MB

### NFR-002: ユーザビリティ要件
- レスポンシブデザイン（320px〜）
- タッチデバイス対応
- キーボードショートカット
- アクセシビリティ（WCAG 2.1 AA準拠）

### NFR-003: セキュリティ要件
- すべての処理をクライアントサイドで実行
- 画像データの外部送信禁止
- XSS対策の実装
- Content Security Policyの設定

### NFR-004: 互換性要件
- ブラウザ: Chrome 90+, Safari 14+, Firefox 88+, Edge 90+
- 画像形式: JPEG, PNG, WebP, GIF（入力）
- 出力形式: JPEG, PNG, WebP

### NFR-005: 可用性要件
- 静的ホスティングでの配信
- CDNによる高速配信
- オフライン時の適切なエラー表示

## 10. 制約事項

### 技術的制約
- ブラウザのメモリ制限による最大処理画像サイズ
- Canvas APIの最大サイズ制限（ブラウザ依存）
- 同時処理可能なファイル数の上限

### ビジネス制約
- 開発期間: 3ヶ月
- 初期リリースはMVP機能のみ
- 広告なしでの運営（初期フェーズ）

## 11. リスクと対策

### リスク1: 大容量ファイルでのメモリ不足
**対策**:
- 段階的な画像処理
- 画像サイズの事前チェックと警告
- メモリ使用量のモニタリング

### リスク2: ブラウザ間の挙動差異
**対策**:
- 徹底的なクロスブラウザテスト
- Polyfillの活用
- 機能検出によるフォールバック

### リスク3: モバイルでの操作性
**対策**:
- タッチ操作に最適化したUI
- モバイル専用のレイアウト
- ジェスチャー操作の実装
