# 用語集 - ガゾウツナゲール

## 1. はじめに

このドキュメントは「ガゾウツナゲール」プロジェクトで使用されるドメイン用語、ビジネス用語、技術用語の統一的な定義を提供します。
チーム内での認識共有とコミュニケーションの円滑化を目的としています。

## 2. ドメイン用語（ビジネス領域）

### 画像処理関連

| 用語 | 英語 | 定義 | 使用例 |
|------|------|------|--------|
| **結合** | Merge | 複数の画像を1つの画像にまとめる処理全般 | 「3枚の領収書画像を結合する」 |
| **配置** | Arrangement | 画像をどのように並べるかの指定 | 「横並び配置」「縦並び配置」 |
| **余白** | Margin | 画像と画像の間の空間 | 「余白を10pxに設定する」 |
| **マージン** | Margin | 余白と同義（コード内では主にmargin） | `margin: 10px` |
| **パディング** | Padding | 結合画像全体の外側の余白 | 「パディングを追加して見やすくする」 |
| **リサイズ** | Resize | 画像のサイズを変更する処理 | 「大きな画像をリサイズして表示」 |
| **アスペクト比** | Aspect Ratio | 画像の縦横比 | 「アスペクト比を保持して拡大」 |
| **プレビュー** | Preview | 実際の結合結果を事前に確認する機能 | 「プレビューで確認してからダウンロード」 |

### UI/UX関連

| 用語 | 英語 | 定義 | 使用例 |
|------|------|------|--------|
| **ドロップゾーン** | Drop Zone | ファイルをドラッグ&ドロップできる領域 | 「ドロップゾーンに画像をドラッグ」 |
| **サムネイル** | Thumbnail | 画像の小さなプレビュー表示 | 「サムネイル一覧から選択」 |
| **アップロード** | Upload | ローカルファイルを選択してアプリに読み込む処理 | 「画像をアップロードする」 |
| **ダウンロード** | Download | 結合した画像をローカルに保存する処理 | 「結合画像をダウンロード」 |
| **エクスポート** | Export | ダウンロードと同義、より一般的な表現 | 「PNG形式でエクスポート」 |

### ユーザー行動関連

| 用語 | 英語 | 定義 | 使用例 |
|------|------|------|--------|
| **領収書結合** | Receipt Merging | 複数の領収書画像を1つにまとめる作業 | 「経費精算用の領収書結合」 |
| **書類整理** | Document Organization | 複数の書類画像を整理・結合する作業 | 「契約書の書類整理」 |
| **SNS投稿用画像作成** | Social Media Image Creation | SNSに投稿するために複数画像を結合 | 「Instagram用の画像作成」 |

## 9. 用語使用時の注意点

### 統一すべき表記

| 推奨 | 非推奨 | 理由 |
|------|-------|------|
| ガゾウツナゲール | 画像つなげーる、がぞうつなげーる | 正式なプロダクト名 |
| 画像結合 | 画像マージ、画像連結 | 日本語として自然 |
| アップロード | ファイル選択 | 一般的な用語 |
| ダウンロード | 保存、エクスポート | 一般的な用語 |
| プレビュー | 確認、表示 | 機能を正確に表現 |

| コンテキスト | 使用用語 | 例 |
