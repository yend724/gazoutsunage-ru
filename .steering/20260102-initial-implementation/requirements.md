# 初回実装要求仕様書

## 概要
「ガゾウツナゲール」の初回実装として、画像結合機能の基本的な実装を行います。

## 実装範囲

### フェーズ1: MVP（最小限の機能）
本フェーズでは、最小限の画像結合機能を実装します。

#### 1. 画像アップロード機能
- **ドラッグ&ドロップ対応**: 複数画像を一度にドロップ可能
- **ファイル選択対応**: クリックでファイル選択ダイアログを表示
- **対応形式**: JPEG、PNG
- **ファイルサイズ制限**: 10MB/ファイル
- **アップロード可能枚数**: 最大10枚

#### 2. 画像プレビュー機能
- **サムネイル表示**: アップロードした画像のサムネイル一覧
- **順序変更**: ドラッグ&ドロップで画像の順序を変更可能
- **削除機能**: 不要な画像を個別に削除

#### 3. 結合設定機能
- **配置方法**: 
  - 横並び（デフォルト）
  - 縦並び
- **間隔設定**: 0px（デフォルト）

#### 4. 結合処理機能
- **Canvas API使用**: ブラウザ上で画像結合処理
- **プログレス表示**: 処理中の進捗を表示

#### 5. ダウンロード機能
- **出力形式**: PNG形式のみ
- **ファイル名**: `merged_[timestamp].png`

## ユーザーストーリー

### US-001: 画像のアップロード
```
As a ユーザー
I want to 複数の画像をアップロードする
So that 画像を結合できる
```

**受け入れ条件:**
- [ ] ドラッグ&ドロップで複数画像を一度にアップロードできる
- [ ] ファイル選択ダイアログから画像を選択できる
- [ ] JPEG、PNG形式の画像をアップロードできる
- [ ] 10MBを超えるファイルはエラーメッセージを表示して拒否される
- [ ] 非対応形式のファイルはエラーメッセージを表示して拒否される

### US-002: 画像の並び替え
```
As a ユーザー
I want to アップロードした画像の順序を変更する
So that 望む順序で画像を結合できる
```

**受け入れ条件:**
- [ ] サムネイル一覧で画像の順序を確認できる
- [ ] ドラッグ&ドロップで画像の順序を変更できる
- [ ] 不要な画像を削除できる

### US-003: 画像の結合
```
As a ユーザー
I want to 複数の画像を1つに結合する
So that 1つの画像ファイルとして保存できる
```

**受け入れ条件:**
- [ ] 横並び・縦並びを選択できる
- [ ] 画像アップロード・順序変更・配置変更時に自動的にプレビューが更新される
- [ ] 「ダウンロード」ボタンをクリックして結合画像を保存できる

### US-004: 結合画像のダウンロード
```
As a ユーザー
I want to 結合した画像をダウンロードする
So that ローカルに保存して使用できる
```

**受け入れ条件:**
- [ ] PNG形式でダウンロードできる
- [ ] ファイル名にタイムスタンプが含まれる
- [ ] ダウンロード完了の確認ができる

## 非機能要件

### パフォーマンス
- 画像10枚（各5MB）の結合処理が10秒以内に完了すること
- アップロード時のプレビュー生成が1秒以内に完了すること

### ユーザビリティ
- 直感的な操作で画像結合ができること
- エラー時には分かりやすいメッセージを表示すること
- 処理中は適切なフィードバックを提供すること

### ブラウザ対応
- Chrome（最新版）
- Safari（最新版）
- Edge（最新版）

## 制約事項

### 技術的制約
- サーバーサイド処理は行わない（完全にクライアントサイドで完結）
- 外部APIは使用しない
- ローカルストレージは使用しない（セッション中のみデータ保持）

### 機能的制約
- 画像の編集機能（回転、リサイズ等）は含まない
- テンプレート機能は含まない
- 履歴機能は含まない
